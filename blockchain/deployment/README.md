# KeyLifecycleRegistry Deployment

## Contract

KeyLifecycleRegistry

## Blockchain Network

Hardhat Local Network

## Solidity Version

0.8.34

## Contract Purpose

Stores tamper-evident lifecycle evidence for AES keys used
in the Healthcare IoT Key Management Framework.

## Lifecycle Events

- CREATED
- ROTATED
- REVOKED
- ARCHIVED
- EXPIRED
- RECOVERED

## On-Chain Data

The contract stores:

- Key ID
- Key version
- Lifecycle event type
- Record hash
- Blockchain timestamp
- Recording blockchain address

## Sensitive Data Policy

The following must NEVER be stored on-chain:

- Plaintext AES keys
- Patient medical records
- Passwords
- JWT secrets
- AES master key
- Database credentials
- Blockchain private keys

## ABI Source

The contract ABI is generated by Hardhat at:

artifacts/contracts/KeyLifecycleRegistry.sol/KeyLifecycleRegistry.json

## Local Deployment

The contract is currently deployed and tested on
the local Hardhat network.

A persistent deployment address will be generated later
